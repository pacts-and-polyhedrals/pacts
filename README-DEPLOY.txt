HOW TO PUBLISH TO GITHUB PAGES
1. Extract THIS ZIP on your computer; do not upload the ZIP as a single file.
2. Open https://github.com/pacts-and-polyhedrals/pacts
3. On the main branch, choose Add file > Upload files.
4. Drag in index.html, about.html, and the ENTIRE assets folder contents.
   Confirm that index.html is in the repository ROOT, not a nested folder.
5. Commit changes to main. Wait for the GitHub Pages deployment to finish.
6. Open https://pacts-and-polyhedrals.github.io/pacts/#products
   and click Explore The Smoke to verify the destination.
7. Optional cleanup: delete the old unused apply_smoke.py and README.txt
   from the GitHub repository; those were part of the earlier patch-only ZIP.
