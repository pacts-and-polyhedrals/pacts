Publisher policies

Beta status and known limitations.

Draft for review · No public paid transactions authorised yet.

The Smoke is currently in beta testing. v0.5.15 is the most recent supplied local build, not a confirmed published commercial release. Features, balance, story content, art and installation requirements may change.

What works in the submitted build

Foundry v14 game system package, London maps and places, missions and local activities, vehicles and chase mechanics, the Blower, GM screen and studio messaging, Banana Watch, character tools and supplied system compendia. These are source-package features, not guarantees of production readiness.

What remains experimental

  • Forge-hosted private-manifest install and automatic update behaviour remains unverified.
  • Some missions, complex driving results and GM/client coordination require live two-account testing.
  • Installed package manifests currently reference the historical public GitHub update URL. A private personal manifest may install a ZIP, but automatic updates cannot be promised until installed-manifest behaviour is verified and migrated.
  • Radio broadcaster websites, stream availability, and narrative integrations are operated by independent third parties.
  • All future release dates are subject to actual testing and publisher approval.

Installation and backup

First sign in to My Library, then download your entitled ZIP. Back up the current Foundry world. For a local Foundry installation, stop the Foundry server, unpack the ZIP so system.json sits directly inside Data/systems/the-smoke/, restart Foundry and confirm the system appears. The game-system ZIP must not be mixed into your world folder.

Attempting the personal manifest URL in Foundry's Install System dialog is optional while unverified. For Forge, check the host's current manual custom-system installation guidance or support; do not claim ordinary asset-library uploads can install a system unless Forge confirms this. Updates should initially use entitled manual ZIPs and verified world backups.
