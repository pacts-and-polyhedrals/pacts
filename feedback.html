Beta feedback.

The Smoke is currently in beta. Let us know what broke, which Foundry/Forge version you used and how to reproduce it. Purchaser sign-in is required.

Submit a report.

Reports go to the private beta feedback database, not a publicly readable GitHub issue. Avoid including access tokens, real customer details or spoilers.

What helps us fix it?

  1. Which Foundry v14 build and whether it's Forge-hosted
  2. The Smoke system version and other installed modules
  3. What you clicked, rolled, or moved
  4. What should have happened
  5. Whether the problem also occurs in a new test world

Want updates? Essential release/security notices come with the product. Optional marketing emails are separately controlled in My Library.
